PREVIEW:
Open index.html in a browser.

PUBLISH FREE:
1. Create a GitHub account at https://github.com/
2. Create a new public repository (for example: mova-crunch-website).
3. Upload index.html and the assets folder, keeping the same folder structure.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will provide a public website link after publishing.
